# Ejercicio 00: Preparar el espacio de trabajo de GitHub Actions

## 1. Objetivo

Preparar un repositorio personal para realizar los ejercicios de GitHub Actions.

## 2. Entorno de trabajo

- Sistema operativo: Windows.
- Editor: Visual Studio Code.
- Control de versiones: Git.
- Versión de Git: 2.56.0.
- Repositorio remoto: https://github.com/001-anais/practicas-github-actions

## 3. Configuración realizada

- Instalación y comprobación de Git.
- Configuración del nombre y correo del usuario.
- Creación de un repositorio personal en GitHub.
- Clonación del repositorio en el ordenador.
- Preparación de las carpetas `.github/workflows/` y `soluciones/`.
- Configuración del repositorio remoto mediante `origin`.

## 4. Comprobaciones

Se ha ejecutado `git remote -v` para comprobar la conexión con GitHub.

Se ha ejecutado `git status` para comprobar que el repositorio está sincronizado y no tiene cambios pendientes.

## 5. Resultado

El entorno de trabajo está preparado para comenzar los ejercicios de GitHub Actions.
